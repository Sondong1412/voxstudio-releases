# Vox-Studio — bộ cài và bản cập nhật

Tải bộ cài Vox-Studio ở mục **[Releases](https://github.com/sondong1412/voxstudio-releases/releases/latest)**
(`VoxStudio-Setup-<phiên bản>.exe`).

Repo này chỉ chứa các tệp phát hành: bộ cài, gói cập nhật và bản sao manifest đã ký.
Vox-Studio đã cài sẽ tự kiểm tra và tải bản mới từ đây. Repo không chứa mã nguồn.
